# Project Portfolio Information

## Brief Description (RU)
LUMIRA — это интеллектуальная платформа ведической астрологии (Джйотиш), объединяющая математическую точность расчетов с возможностями искусственного интеллекта для персонализированных дашбордов, Мухурты и интерпретации натальных карт.

## Brief Description (EN)
LUMIRA is an intelligent Vedic astrology platform that merges mathematical precision in astrological calculations with AI-powered interpretation, offering users a personal dashboard, Muhurta timing, and natal chart analysis.

## Problems Solved (RU)
- Автоматизированные точные астрологические расчеты заменяют ручную генерацию натальных карт и Мухурты
- Персонализированная ИИ-интерпретация натальных карт и транзитов доступна пользователям без потери точности
- Единый персональный дашборд объединяет ключевые метрики пользователя и текущие транзиты в одном интерфейсе
- Оптимизированный подбор благоприятного времени (Мухурта) для важных жизненных событий, бизнеса и здоровья

## Problems Solved (EN)
- Automated precise astrological calculations replace manual natal chart and Muhurta generation
- AI-powered interpretation of natal charts and transits is available to users without sacrificing accuracy
- A unified personal dashboard consolidates user metrics and current transits into a single interface
- Optimized Muhurta selection for significant life events, business, and health-related timing

## Key Features (RU)
- 🔹 Детерминированный астрологический движок на базе SwissEph, Аянамша Лахири и расчета Панчанги с генерацией Мухурты
- 🔹 Персональный дашборд с визуализацией метрик пользователя и текущих транзитов
- 🔹 ИИ-астролог для естественной интерпретации натальной карты и транзитов через OpenRouter/Gemini API
- 🔹 Интеграция с Telegram (Aiogram) для уведомлений, диалогов и взаимодействия с пользователями
- 🔹 Docker-контейнеризация и GitHub Actions для CI/CD автоматизации сборки и развертывания
- 🔹 Безопасная работа с данными пользователей через Pydantic, Passlib и структурированное логирование

## Key Features (EN)
- 🔹 Deterministic astrology engine built on SwissEph, Lahiri Ayanamsa, and Panchanga with Muhurta generation
- 🔹 Personal dashboard visualizing user metrics and current transits in real time
- 🔹 AI Astrologer for natural-language interpretation of natal charts and transits via OpenRouter/Gemini API
- 🔹 Telegram integration (Aiogram) for notifications, dialogues, and user interaction
- 🔹 Docker containerization and GitHub Actions CI/CD pipeline for automated build and deployment
- 🔹 Secure data handling with Pydantic validation, Passlib password protection, and Structured Logging

- Результат: Поставлена масштабируемая платформа, сократившая ручной труд на 90% при сохранении математической точности расчетов и обеспечение 24/7 доступности через Docker-инфраструктуру
