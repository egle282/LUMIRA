## О проекте

**LUMIRA — это интеллектуальная платформа ведической астрологии (Джйотиш), объединяющая математическую точность астрологических вычислений с мощью искусственного интеллекта. Платформа предоставляет пользователям персональный дашборд, расчет Мухурты (благоприятного времени для событий) и ИИ-чат для интерпретации натальной карты.**

Этот проект демонстрирует:
- Высокие стандарты разработки ПО
- Интеграцию со сторонними библиотеками и API
- Воспроизводимую структуру и поддерживаемую документацию
