# Контрольный список готовности к релизу (Release Checklist)

Документ фиксирует фактическое состояние готовности LUMIRA к публичному / бета-релизу на основании инструментальной проверки.

## Чек-лист готовности

- [x] **Воспроизводимый запуск:**
  - `docker compose config -q` завершается с кодом 0.
  - Контейнеры `db`, `redis`, `backend`, `frontend` запускаются стабильно, `db` и `redis` переходят в состояние `healthy`.
- [x] **Backend работает:**
  - HTTP эндпоинт `/api/health` возвращает `200 OK` (`{"status":"ok"}`).

## Задокументированные ограничения и непроверенные области

1. **Мухурта (Muhurta):**
   - Реализован серверный почасовой скрининг Панчанги на выбранную дату (предварительная эвристика). Не является классическим полным расчётом мухурты (не учитывает индивидуальные лагны интервалов, Раху-кала и восход/закат).
2. **Внешние платёжные шлюзы (Stripe Live):**
   - Проверена логика fail-closed и тестовые сессии Checkout/Portal. Реальные денежные транзакции не проводились из соображений безопасности.
   - Оплата через Telegram Stars находится в статусе «не реализована».
3. **AI LLM API:**
   - Без действующего ключа `OPENROUTER_API_KEY` или `LLM_API_KEY` работает детерминированный fallback. Реальные запросы к платным LLM не тарифицировались.
4. **Хранение Feature Flags:**
   - Эндпоинт `/api/admin/feature-flags` возвращает `501 Not Implemented` (персистентное хранилище флагов вынесено в будущие версии).
