# Autonomous Engineering Workflow

For a substantial task:

```bash
python .antigravity/router/runtime/run.py "YOUR TASK"
```

Then Gemini/Antigravity uses the generated run bundle to:
1. inspect route
2. inspect context manifest
3. load selected agents/skills/rules
4. plan
5. implement
6. test
7. review
8. record experience
9. propose improvements when evidence exists

The system should become better through validated evidence, not through uncontrolled self-modification.
