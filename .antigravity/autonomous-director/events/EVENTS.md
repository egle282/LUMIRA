# Event Journal

Record meaningful lifecycle events:

- task.received
- route.created
- context.loaded
- plan.created
- approval.requested
- approval.granted
- approval.denied
- implementation.started
- implementation.completed
- test.completed
- review.completed
- drift.detected
- lesson.proposed
- lesson.promoted
- state.updated
- deployment.completed

Events should be structured, timestamped, and free of secrets/private credentials.
