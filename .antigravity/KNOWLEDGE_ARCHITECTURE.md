# AI PROJECT OS Knowledge Architecture

Separate knowledge by stability:

```text
00-core/
  system principles, safety, invariants

10-project/
  current architecture, domain, contracts

20-skills/
  reusable technical methods

30-experience/
  validated lessons from completed work

40-evals/
  regression tests for AI behavior

50-proposals/
  unvalidated improvement proposals
```

## Important
Experience is not automatically truth.
Project facts outrank generic lessons.
Validated lessons may be promoted into skills/rules.
Old lessons remain versioned so the system can roll back.
