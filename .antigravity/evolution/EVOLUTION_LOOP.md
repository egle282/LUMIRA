# Evolution Loop v1

After each meaningful task:

1. Capture outcome.
2. Compare expected vs actual.
3. Extract failures and repeated friction.
4. Cluster similar incidents.
5. Draft a lesson.
6. Validate against code/tests/reviewer evidence.
7. Promote only validated lessons.
8. Run regression evaluations.
9. Keep rollback/version history.

This turns project history into a controlled engineering knowledge base.
