# Experience Log

This is the system's operational memory. It stores *what happened*, not private user data.

For each completed task record:
- task class
- route used
- relevant files
- tests/checks
- failures
- root cause
- repair
- reviewer findings
- reusable lesson
- confidence
- whether the lesson was promoted to a rule/skill

Never store secrets, credentials, personal data, or raw private conversations.
Prefer short structured records over giant transcripts.
