**ВНИМАНИЕ, ИИ-АГЕНТ**: Вы ОБЯЗАНЫ выполнить эти шаги перед совершением ЛЮБЫХ действий в рабочем пространстве:

1. **Анализ структуры проекта**: Изучить текущую структуру LUMIRA, включая frontend, backend сервисы, компоненты и маршрутизацию.
    🧠 **Протокол работы с контентом**:
    1. **Проверка контента**: Анализировать MDX-файлы в `content/domains/` и `content/case-studies/` для понимания структуры.
    2. **Сохранение целостности**: ИИ НЕ производит мутаций структуры контента без явного подтверждения.
    3. **Актуализация конфигураций**: ИИ обновляет конфигурационные файлы в `.antigravity/` в соответствии с текущим состоянием проекта.
    4. **Фиксация контекста**: ИИ считывает `AI_PLAN.md` и `PROJECT_STATUS.md` для восстановления полного контекста требований.

2. **Изучение директории .antigravity**: Эта папка — «Мозг» репозитория. ВСЕ файлы здесь являются ИСТИНОЙ.
    - `session_handoff.md`: Самое актуальное техническое состояние и правила фиксации сессий.
    - `security-context.md`: Критические правила безопасности и окружения.
    - папки `rules`, `skills`, `cortex`, `security-prompts`, `commands`, `workflows` ОБЯЗАТЕЛЬНЫ к прочтению и ИСПОЛЬЗОВАНИЮ данных из них как руководство в работе с проектом.
    - файлы из папки `.planning` держать в актуальном состоянии и использовать в работе с проектом.
    - `ralph.sh` (в корне и в `.antigravity/`) и папка `.antigravity/ralph`: Автономный агентный цикл Ralph, адаптированный под Gemini (`agy`) и Claude Code для автоматического выполнения бэклог-задач из `prd.json`. Использовать его при работе над проектом для автоматизации.

3. **Правило работы с контентом и документацией**:
    - ⛔ **ИИ СТРОГО ЗАПРЕЩЕНО изменять структуру MDX-файлов без явного подтверждения**.
    - 🟢 **ВСЕ изменения контента подлежат валидации через frontmatter схемы**.
    - 🟢 **Синхронизация с документацией**: По завершении сессии обновлять документацию в соответствии с изменениями.
