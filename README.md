# LUMIRA 🌌

LUMIRA — это интеллектуальная платформа ведической астрологии (Джйотиш), объединяющая математическую точность астрологических вычислений с мощью искусственного интеллекта. Платформа предоставляет пользователям персональный дашборд, расчет Мухурты (благоприятного времени для событий) и ИИ-чат для интерпретации натальной карты.

## 🚀 Основной функционал

*   **Персональный дашборд:** Визуализация ключевых метрик пользователя и текущих транзитов.
*   **Astrology Engine:** Детерминированные астрологические расчеты (SwissEph, Аянамша Лахири, расчет Панчанги, расчет Мухурты) — выступает как источник истины.
*   **ИИ-астролог (AI Chat):** Интеллектуальная интерпретация натальных карт и транзитов. LLM не делает вычислений, а интерпретирует данные, предоставленные Astrology Engine (через OpenRouter/Gemini API).
*   **Мухурта (Muhurta):** Выбор благоприятного времени для бизнеса, свадеб, путешествий и здоровья.

## 🛠 Технологический стек

*   **Frontend:** React, TypeScript, Vite, Tailwind CSS, Lucide React (Premium Glassmorphism UI).
*   **Backend:** Python, FastAPI, SQLAlchemy, PostgreSQL.
*   **Astrology:** `pyswisseph` (ведические расчеты).
*   **AI Integration:** OpenRouter API (Gemini/Llama), LangChain.
*   **DevOps:** Docker, GitHub Actions (CI/CD), Pytest.

## 🧠 Принципы архитектуры

Главный архитектурный принцип LUMIRA: **Astrology engine является детерминированным слоем и единственным источником истины (source-of-truth).** LLM не должен самостоятельно вычислять астрологические значения. LLM отвечает исключительно за интерпретацию, эмпатию, персонализацию и ведение естественного диалога.
