# LUMIRA 🌌

LUMIRA — это интеллектуальная платформа ведической астрологии (Джйотиш), объединяющая математическую точность астрологических вычислений с мощью искусственного интеллекта. Платформа предоставляет пользователям персональный дашборд, расчет Мухурты (благоприятного времени для событий) и ИИ-чат для интерпретации натальной карты.

## 🚀 Основной функционал

*   **Персональный дашборд:** Визуализация ключевых метрик пользователя и текущих транзитов.
*   **Astrology Engine:** Детерминированные астрологические расчеты (SwissEph, Аянамша Лахири, расчет Панчанги) — выступает как источник истины.
*   **ИИ-астролог (AI Chat):** Интеллектуальная интерпретация натальных карт и транзитов. LLM не делает вычислений, а интерпретирует данные, предоставленные Astrology Engine.
*   **Мухурта (Muhurta):** Выбор благоприятного времени (В настоящее время UI-mock, бекенд в разработке).

## 🛠 Технологический стек

*   **Frontend:** React, TypeScript, Vite, Tailwind CSS, Lucide React (Premium Glassmorphism UI).
*   **Backend:** Python, FastAPI, SQLAlchemy, PostgreSQL.
*   **Astrology:** `pyswisseph` (ведические расчеты).
*   **AI Integration:** OpenRouter API (Gemini/Llama), LangChain.
*   **DevOps:** Docker, GitHub Actions (CI/CD), Pytest.

## 🧠 Принципы архитектуры

Главный архитектурный принцип LUMIRA: **Astrology engine является детерминированным слоем и единственным источником истины (source-of-truth).** LLM не должен самостоятельно вычислять астрологические значения. LLM отвечает исключительно за интерпретацию, эмпатию, персонализацию и ведение естественного диалога.

## 📂 Структура проекта

*   `/frontend` — Клиентская часть (React SPA)
*   `/backend` — Серверная часть (FastAPI, AI orchestration, SwissEph engine)
*   `/docPRO` — Сгенерированная техническая и маркетинговая документация
*   `.antigravity` — Директория сессий и рабочих протоколов для агентов Antigravity

## 🏁 Локальный запуск (Быстрый старт)

Для безопасного запуска проекта локально выполните следующие шаги:

1. **Клонируйте репозиторий:**
   ```bash
   git clone https://github.com/egle282/LUMIRA.git
   cd LUMIRA
   ```
2. **Настройте переменные окружения:**
   Скопируйте пример файла конфигурации:
   ```bash
   cp .env.example .env
   ```
   *Откройте `.env` и впишите ключи доступа к API.*

3. **Запустите проект в Docker:**
   ```bash
   docker-compose up --build
   ```
   *Доступ к фронтенду будет по адресу: `http://localhost:5173`.*

## 🔒 Безопасность и ограничения

- **Development Compose:** Локальный `docker-compose.yml` не предназначен для production. Порты базы данных привязаны только к `127.0.0.1`.
- **Tenant Isolation:** Механизмы изоляции клиентов (RLS) и биллинг находятся в стадии интеграции. Не используйте текущую версию для открытой SaaS-эксплуатации без доработки.
