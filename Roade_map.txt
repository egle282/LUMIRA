И главное

Я бы не начинал LUMIRA с красивого frontend.

Правильный порядок:
ASTROLOGY TRUTH
        ↓
DOMAIN MODEL
        ↓
DATABASE
        ↓
API
        ↓
AI ORCHESTRATION
        ↓
TELEGRAM
        ↓
WEB
        ↓
BILLING
        ↓
ADMIN
        ↓
PRODUCTION

Потому что если сначала сделать интерфейс, а потом обнаружить, что Panchanga/Dasha/Muhurta, timezone, location и tenant model спроектированы неправильно, придётся переделывать половину продукта.

Первый запуск этого prompt в Antigravity должен привести не к коду, а к PHASE 0 DISCOVERY → ARCHITECTURE → ROADMAP → DATABASE PLAN → AI PLAN → SECURITY MODEL. После этого система уже может идти по фазам практически автономно.
