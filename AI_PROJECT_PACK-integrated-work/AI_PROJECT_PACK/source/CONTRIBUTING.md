# CONTRIBUTING.md

Read AGENTS.md, USER.md, PROJECT_STATUS.md, and SECURITY.md before work. Check manifest files and git status.

Make a focused diff and do not destroy uncommitted changes. Run the factual lint, type check, test, build, security, and secret commands listed in PROJECT_STATUS.md.

PR description must contain goal, changed files, checks, security impact, migrations, rollback, and limitations.

Push, merge, release, deployment, payments, and external publication require confirmation.

Never commit .env, credentials, keys, session history, personal memory, logs, or temporary artifacts.
